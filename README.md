# PoC 5 – Flexible JSON-Visualisierung



Dieser PoC testet die dynamische Darstellung unterschiedlicher JSON-Strukturen in einer TreeView und WebView.



## Test



Im Ordner dieser README ein Terminal öffnen:



```powershell

dotnet run --project AvaloniaJsonVisualization/AvaloniaJsonVisualization.csproj

```



In der Anwendung:



1\. Ein Beispiel über die Auswahlliste auswählen.

2\. Einen Wert im JSON-Editor verändern.

3\. Die TreeView- und WebView-Ausgabe kontrollieren.



## Erwartetes Ergebnis



Änderungen am JSON werden automatisch verarbeitet und in TreeView und WebView dargestellt.
